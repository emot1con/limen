# AGENTS.md

## Scope

These instructions apply to this repository, which contains the Limen backend.

## Conflict handling

When user instructions, specifications, documentation, or implementation conflict, do not guess which one is authoritative. Point out the conflicting details and ask the user to confirm before proceeding.

## Testing

Unit and integration testing are deferred until the system implementation is complete. Do not treat missing tests as a blocker before then.
